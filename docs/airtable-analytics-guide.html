Airtable Analytics 캐싱 시스템 설정

Google Analytics 데이터를 Airtable에 저장하여 API 호출을 최소화합니다.

진행 상황

1
2
3

Base 생성 테이블 생성 API 키 환경변수

Step 1: Airtable Base 생성

  1. Airtable 로그인
  2. + Create a base 클릭
  3. Base 이름: choho_analytics

Step 2: 테이블 5개 생성

1. analytics_summary

필드명 타입 설명
dateDate날짜
totalUsersNumber총 사용자
newUsersNumber신규 사용자
sessionsNumber세션 수
pageViewsNumber페이지뷰
avgSessionDurationNumber평균 세션 시간(초)
bounceRateNumber이탈률(%)
syncedAtDate (Include time)동기화 시간

2. analytics_pages

필드명 타입
dateDate
pathSingle line text
titleSingle line text
viewsNumber
syncedAtDate (Include time)

3. analytics_sources

필드명 타입
dateDate
sourceSingle line text
mediumSingle line text
usersNumber
sessionsNumber
syncedAtDate (Include time)

4. analytics_devices

필드명 타입
dateDate
deviceSingle line text
usersNumber
sessionsNumber
pageViewsNumber
syncedAtDate (Include time)

5. analytics_keywords

필드명 타입
dateDate
querySingle line text
clicksNumber
impressionsNumber
ctrNumber
positionNumber
syncedAtDate (Include time)

Step 3: API 키 및 Base ID 획득

  1. Personal Access Token 페이지 접속
  2. Create new token 클릭
  3. Token 이름: choho-analytics
  4. Scopes 선택:
    • data.records:read
    • data.records:write
    • schema.bases:read
  5. Access: choho_analytics base 선택
  6. Create token 클릭

중요: 토큰은 한 번만 표시됩니다. 안전한 곳에 복사해두세요.

Base ID 확인

Base URL에서 확인: https://airtable.com/appXXXXXXXXXXXXXX/...

Step 4: 환경변수 설정

.env.local 파일에 추가:

# Airtable 설정
AIRTABLE_API_KEY=여기에_API_KEY_입력
AIRTABLE_BASE_ID=여기에_BASE_ID_입력

Vercel 환경변수 (프로덕션)

  1. Vercel Dashboard → 프로젝트 선택
  2. Settings → Environment Variables
  3. 위의 두 변수 추가

설정 완료!
