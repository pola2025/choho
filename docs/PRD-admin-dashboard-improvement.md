# PRD: 관리자 대시보드 개선

**문서 버전**: 1.0.0
**작성일**: 2025-12-22
**상태**: 기획 중

---

## 1. 개요

### 1.1 목적
초호펜션 관리자 대시보드의 네이버 광고 분석 기능 강화 및 모바일 반응형 UI 최적화

### 1.2 배경
- 현재 네이버 광고 일별 데이터가 44일만 표시되는 문제
- 기간 필터가 제대로 작동하지 않음
- AI 기반 인사이트 분석 기능 부재
- 모바일에서 관리자 대시보드 사용성 저하

---

## 2. 우선순위

| 순서 | 작업 | 우선순위 | 복잡도 |
|------|------|----------|--------|
| 1 | 데이터 완전성 확보 (24년~25년 전체 데이터) | **Critical** | 중 |
| 2 | 기간 필터 버그 수정 | **Critical** | 하 |
| 3 | 일별 데이터 월별 그룹핑 UI (접힘/펼침) | **High** | 중 |
| 4 | AI 분석 기능 추가 | **High** | 상 |
| 5 | 모바일 반응형 최적화 | **Medium** | 상 |

---

## 3. Phase 1: 데이터 분석 기능 강화

### 3.1 데이터 완전성 확보

#### 3.1.1 현재 상태
- Airtable `naverAdDaily` 테이블에 44일치 데이터만 존재
- 백필 스크립트 (`scripts/backfill-naver-ad.js`) 존재하나 전체 기간 미실행

#### 3.1.2 요구사항
- 2024년 1월 ~ 현재까지 모든 일별 데이터 백필
- 데이터 범위: 약 720일 (2년)

#### 3.1.3 구현 방안
```
1. 백필 스크립트 실행하여 2024-01-01 ~ 현재 데이터 수집
2. Airtable 데이터 정합성 확인
3. 누락 날짜 자동 감지 및 재수집 로직 강화
```

### 3.2 기간 필터 버그 수정

#### 3.2.1 현재 상태
- `naver-daily` API가 startDate/endDate 파라미터를 받지만 기본값만 적용
- UI에서 날짜 변경 시 데이터가 갱신되지 않는 문제

#### 3.2.2 원인 분석
```typescript
// route.ts:578-596
if (type === 'naver-daily') {
  // startDate/endDate가 없으면 이번 달 1일~오늘로 기본 설정
  const queryStartDate = startDate || thisMonthStart;
  const queryEndDate = endDate || todayStr;
  // Airtable에서 조회 - 여기서 날짜 필터 적용됨
  const cachedDaily = await getNaverAdDaily(queryStartDate, queryEndDate);
}
```

- API는 정상 작동하나, UI에서 날짜 변경 시 재요청하지 않음

#### 3.2.3 수정 방안
```typescript
// naver-ads/page.tsx 수정
// 1. dateRange 변경 시 일별 데이터도 함께 갱신
// 2. 의존성 배열에 dateRange 추가
// 3. 일별 탭에서도 날짜 선택기 표시
```

## 4. Phase 2: 모바일 반응형 최적화

### 4.1 레이아웃 개선

#### 4.1.1 현재 문제점
- 사이드바 `w-56` 고정으로 모바일에서 화면 차지
- 모바일용 햄버거 메뉴 없음

#### 4.1.2 수정 방안
```
[Mobile: < 768px]
- 사이드바 숨김 (기본)
- 햄버거 버튼으로 슬라이드 오버레이 메뉴 토글
- 헤더에 현재 페이지명 표시

[Tablet: 768px - 1024px]
- 사이드바 축소 (아이콘만 표시)
- 호버 시 라벨 툴팁

[Desktop: > 1024px]
- 현재 레이아웃 유지
```

### 4.2 네이버 광고 페이지 모바일 최적화

#### 4.2.1 날짜 선택기
```
[Desktop]
시작일 [____] ~ 종료일 [____] [새로고침]

[Mobile]
시작일: [________]
종료일: [________]
[새로고침]
```

#### 4.2.2 요약 카드
```

│   │ │   │ │   │ │   │ │   │
```

#### 4.2.3 테이블
