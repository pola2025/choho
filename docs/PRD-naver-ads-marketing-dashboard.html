1. 프로젝트 개요

목적

네이버 검색광고 API를 활용하여 광고 실적을 종합적으로 분석하고, 일별/주간별/월별/연간 흐름을 시각화하여 마케팅 의사결정을 지원합니다.

대상 사용자

초호펜션 관리자 (마케팅 담당)

연동 서비스

  • 네이버 검색광고 API (Naver Search Ad API)
  • Airtable (데이터 저장/캐싱)

2. 현재 구현 상태

완료된 기능

  • ✓ 네이버 검색광고 API 연동
  • ✓ 관리자 사이드바 메뉴 추가
  • ✓ 요약 통계 카드 (광고비/클릭/노출/CTR/CPC)
  • ✓ 캠페인별 실적 테이블
  • ✓ 키워드 TOP 20 테이블

수정 필요

  • ! 일별 통계 API 버그 (getDailyStats)
  • ! 날짜 기본값 설정 오류

3. 추가 요구사항

시각화 요구사항

  • 일별 광고비/클릭/노출 추이 차트
  • 주간별 누적 성과 차트
  • 월별 누적 성과 차트
  • 연간 흐름 시각화 (12개월 트렌드)

분석 기능

  • 전월 대비 성장률 표시
  • ROAS (광고수익률) 계산
  • 기간별 비교 분석
  • 캠페인별 효율 순위

6. API 엔드포인트

엔드포인트 설명 파라미터 상태
?type=naver-summary 요약 통계 startDate, endDate 완료
?type=naver-daily 일별 통계 startDate, endDate 버그수정
?type=naver-campaigns 캠페인별 통계 startDate, endDate 완료
?type=naver-weekly 주간별 통계 weeks (기본 8) 예정
?type=naver-monthly 월별 통계 months (기본 12) 예정
?type=naver-yearly 연간 통계 year 예정
?type=naver-keywords-sync 키워드 실시간 동기화 yearMonth 완료
