네이버 광고 캠페인별 일별 테이블 설정

Airtable 테이블 생성 및 환경변수 설정 가이드

📋 진행 체크리스트

1

Airtable 테이블 생성

Analytics Base에서 새 테이블을 생성합니다.

Base 접속 경로:

https://airtable.com/appKpdQ8j5jPMapcw
  1. 좌측 하단 + Add or import 클릭
  2. Create blank table 선택
  3. 테이블 이름: NaverAdCampaignDaily
2

필수 필드 생성

다음 필드들을 순서대로 생성합니다:

필드명 타입 설명
recordKeySingle line text고유키 (날짜_캠페인ID)
dateSingle line text날짜 (YYYY-MM-DD)
campaignIdSingle line text캠페인 ID
campaignNameSingle line text캠페인 이름
campaignGroupSingle line text캠페인 그룹 (place-personal, place-group, power-content)
impCntNumber노출수
clkCntNumber클릭수
salesAmtNumber광고비
ctrNumber클릭률 (%)
cpcNumber클릭당 비용
ccntNumber전환수
syncedAtSingle line text동기화 시간 (ISO 형식)

⚠️ 주의: 기본으로 생성되는 Name 필드는 삭제하거나, recordKey로 이름을 변경하세요.

3

테이블 ID 확인

테이블 ID를 확인하는 방법:

  1. 생성한 테이블을 클릭하여 선택
  2. 브라우저 URL 확인
  3. URL 형식: https://airtable.com/appKpdQ8j5jPMapcw/tblXXXXXXXXXXXXX/...
  4. tbl로 시작하는 부분이 테이블 ID입니다
4

환경변수 추가

.env.local 파일에 다음 줄을 추가합니다:

AIRTABLE_NAVER_AD_CAMPAIGN_DAILY_TABLE=tblXXXXXXXXXXXXX

📁 파일 위치: F:\choho_2025\.env.local

기존 네이버 광고 테이블 설정 아래에 추가하세요.

5

백필 스크립트 실행

환경변수 설정 후 백필 스크립트를 실행합니다:

node scripts/backfill-naver-ad-campaign.js

⏱️ 예상 소요 시간:

  • 2024-01-01부터 현재까지: 약 350일 × 4개 캠페인 = ~1,400개 레코드
  • API 호출 제한 고려: 약 10-20분 소요

✅ 설정 완료 후

AI 리포트에서 캠페인별 데이터 분석이 가능해집니다.

  • place-personal: 개인 플레이스 광고
  • place-group: 단체 플레이스 광고
  • power-content: 파워컨텐츠 광고
