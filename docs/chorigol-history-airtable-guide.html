초리골 역사 에어테이블 설정 가이드

초호펜션 웹사이트의 초리골 역사 기록을 에어테이블로 관리하기 위한 설정 가이드입니다.

진행 체크리스트

1

에어테이블 테이블 생성

1. Airtable에 로그인합니다.

2. 기존 "choho" Base를 엽니다.

3. + Add a table 버튼을 클릭합니다.

4. 테이블 이름을 입력합니다:

ChorigolHistory
2

필드 구조 설정

다음 필드들을 생성합니다. (필드명을 정확히 입력하세요)

필드명 타입 설명
year Single line text 연도 (예: "1947년", "현재")
title Single line text 기사 제목
content Long text 기사 본문 내용
source Single line text 출처명 (예: "파주위키")
sourceUrl URL 출처 URL 링크
category Single select 카테고리
order Number (Integer) 정렬 순서 (1, 2, 3...)
viewCount Number (Integer) 조회수 (기본값: 0)
isPublished Checkbox 공개 여부

category 필드 옵션 설정

Single select 필드에 다음 옵션들을 추가하세요:

origin (지명유래) history (근현대사) nature (자연환경) culture (문화유산) development (마을발전)
3

환경 변수 설정

1. 에어테이블에서 Help → API documentation으로 이동합니다.

2. 테이블 ID를 확인합니다. (URL에서 tbl...로 시작하는 부분)

3. .env.local 파일에 다음 환경 변수를 추가합니다:

# 초리골 역사 테이블 ID

AIRTABLE_CHORIGOL_HISTORY_TABLE_ID=tbl여기에테이블ID입력

보안 주의

API 키와 테이블 ID는 절대 공개 저장소에 커밋하지 마세요!

4

초기 데이터 입력

에어테이블 테이블이 비어있으면 기본 20개의 역사 기록이 자동으로 표시됩니다.

에어테이블에서 직접 수정하거나 추가하면 해당 데이터가 우선 표시됩니다.

기본 데이터 목록 (20개)

  • 1. 초리골 지명의 유래 - '꼬리'에서 비롯된 이름
  • 2. 천현면(泉峴面)의 역사 - 샘재의 유래
  • 3. 장군봉 은굴의 은 채광 역사
  • 4. 초호정의 탄생 - 나눔으로 일궈낸 연못
  • 5. 은굴 폐광과 군부대 봉쇄
  • 6. 1.21 사태 - 초리골 삼봉산에서 무장공비 발견
  • 7. 천현면에서 법원읍으로 승격
  • 8. 초리골 마을 운영 규약 제정
  • 9. 자운서원 건립 - 율곡 이이 선생을 기리다
  • 10. 비학산과 12개 봉우리
  • 11. 초리골의 야생동물
  • 12. 장군봉과 장군바위
  • 13. 다산수도원
  • 14. 단양우씨 집성촌
  • 15. 초비클럽 결성
  • 16. 더 초리골 수영장 개장
  • 17. 눈 내리는 초리골 겨울축제 시작
  • 18. 초리골 협동조합 설립
  • 19. 파주의 알프스 - 소득 주도형 마을로 진화
  • 20. 1.21 사태 생존자 김신조 별세

API 엔드포인트

GET /api/chorigol-history

공개된 모든 초리골 역사 기록을 조회합니다.

POST /api/chorigol-history

새로운 역사 기록을 추가합니다.

PATCH /api/chorigol-history

기존 역사 기록을 수정합니다.

DELETE /api/chorigol-history?id={recordId}

역사 기록을 삭제합니다.

설정 완료!

에어테이블 설정이 완료되면 /about 페이지 하단에서 초리골 역사 기록을 확인할 수 있습니다.
